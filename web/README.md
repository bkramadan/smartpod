# Web dashboards

For doctors, pharmacists and caregivers. React + Vite.

```bash
npm install
npm run dev     # http://localhost:5173 (the backend must be running)
npm run build   # production files in dist/
```

Backend address: `VITE_API_URL` in `.env` (default `http://localhost:4000`). Screens are in `src/pages/`.
